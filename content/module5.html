In this chapter, we will explore the concept of arrays, which allow us to store multiple values in a single variable. We will learn how to create, access, and manipulate arrays in our programs.With chapter 5, we move into a data structure called arrays. Arrays are very simply a contiguous series of variables in memory with the same name and data type. We access each element or variable by using a subscript or index. Head's up, Python is a little bit different here. In Python, arrays are not built-in or native so we need to import an array library. The native and more preferred data structure in Python is the list. It works just like an array but allows different data types. While not 100% correct, we are going to treat Python lists basically like arrays.
